栈是一种LIFO (后进先出)的数据结构，最新添加的项最早被移除，插入和移除只发生在一个位置--栈的顶部
---------------------------
push() : 添加项到末尾，返回修改后的数组长度
pop() :  从末尾移除最后一项，返回移除的项
var colors = new Array();
var count = colors.push("red","green");
alert(count);  //2
count = colors.push("black"); //3

var item = colors.pop();
alert(item); //"black"
alert(colors.length);  //2
----------------------------
队形数据结构的访问规则：FIFO（先进先出）
shift() : 移除数组中的第一项并返回该项
var item = colors.shift();
alert(item); //"red" 取得第一项，同时长度减1
--------------------
unshift() : 在数组前端添加任意个项并返回新数组的长度
-------------------------
reverse() : 反转数组项的顺序， colors.reverse();
sort() : 默认升序，可以传递一个函数作为参数  values.sort(compare);
---------------------------
concat() : 复制一个数组并把传递过来的参数添加到数组中
var colors2 = colors.concat("yellow",["black","brown"]);
------------------------
slice(m,n) : 假如只有一个参数，返回m到末尾，否则返回m-n(不包括n),不会影响原数组。 
---------------------------------
splice() : 功能强大，删除，插入，替换，返回一个包含被删除的项的数组，没删除则返回空数组。
删除：colors.splice(0,1);  //删除第一项，1是要删除的个数
插入：colors.splice(1,0,"yellow","orange"); //从位置1开始插入两项
替换：colors.splice(1,1,"red","purple"); //在位置1插入两项，删除1项
-------------------------------
indexOf(),lastIndexOf() : 返回在数组中的位置，没找到返回-1
var numbers = [1,2,3,4,5,4,3,2,1];
alert(numbers.indexOf(4)); //3
alert(numbers.lastIndexOf(4)); //5
